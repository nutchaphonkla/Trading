CLOUDFLARE FALLBACK QUICK SETUP

A) D1
- Cloudflare Dashboard -> Storage & Databases -> D1 -> Create database
- Name: onemonth-tv-feed
- Console -> paste cloudflare-d1-schema.sql -> Execute

B) Worker
- Workers & Pages -> Create Worker
- Paste cloudflare-worker.js
- Settings/Bindings -> Add D1 binding
  Variable name: DB
  Database: onemonth-tv-feed
- Settings/Variables -> Add encrypted secret
  WEBHOOK_TOKEN = create a long random token (at least 32 random characters)
- Deploy
- Copy base URL: https://YOUR-WORKER.workers.dev

C) Test
Open:
https://YOUR-WORKER.workers.dev/
Expected: service status JSON

After TradingView sends at least one bar, open:
https://YOUR-WORKER.workers.dev/public-feed?limit=10
Expected: JSON with timeframes.M1

Do not put the webhook token in GitHub frontend code or index.html.
