ONEMONTH OS V35.0 PYTHON ML BRAIN

WHAT CHANGED
- Python ML ensemble: HistGradientBoosting + ExtraTrees
- Chronological 4-fold walk-forward validation (no random time-series split)
- Purge gap between train/test to reduce lookahead leakage
- Platt probability calibration
- Separate heads for P(fill), P(TP1), P(TP2), P(SL)
- MFE / MAE regression
- Multi-timeframe features from M15 + M5 + H1
- Session/regime/order-type features
- ML drift + model disagreement + governance trust
- Real Pending Plan Journal feedback by order type
- ML ranks BUY LIMIT / SELL LIMIT / BUY STOP / SELL STOP
- Pending Plan works from Last Session even when market is closed
- M1/M5 are revalidation aids, not blockers for creating a waiting plan
- Heavy ML retraining is throttled to roughly once per 4 new M15 bars (~1 hour)

HOW V35 THINKS
Historical candles -> feature engineering -> historical pending candidates -> outcome labels
-> chronological walk-forward -> ML ensemble -> calibrated probabilities
-> rank LIMIT/STOP candidates -> Technical + ML fusion -> PRIMARY / BACKUP Pending Plan
-> journal real fills/results -> feedback into future ranking

IMPORTANT
ML can improve ranking/calibration with more valid data, but it cannot guarantee future profit.
A low validation score, high drift, or high disagreement automatically reduces/quarantines ML influence.
