ONEMONTH OS V36.0 AUTONOMOUS ML PLAN BRAIN

CORE CHANGE
- AI now creates waiting-entry plans, not "enter now" signals.
- Daily Command Center shows exact pending price + zone + SL + TP1 + TP2 + RR/EV + quality grade.
- Weak candidates are shown as REJECTED / DO NOT PLACE instead of PLAN PREPARED.
- A TRUSTED model does NOT automatically make a candidate tradable.

AUTONOMOUS ML
- XGBoost + HistGradientBoosting + ExtraTrees compete with chronological walk-forward OOF validation.
- The system automatically selects model weights for each head: P(fill), P(TP1), P(TP2), P(SL).
- PLATT / ISOTONIC / IDENTITY calibration compete automatically; lowest validation Brier+ECE wins.
- Recency weighting remains enabled.
- Purge gap remains enabled to reduce time-series leakage.
- MFE/MAE regression remains enabled.

HARD PLAN QUALITY GATE
A pending candidate can become QUALIFIED only when the deployed ML is trusted and the candidate passes dynamic rules for:
- Plan score
- Expected value
- P(TP1)
- P(SL)
- TP1-vs-SL probability edge
- Model disagreement

If all candidates fail, the app displays NO QUALITY PLAN. It still shows the best rejected reference price so you can see what the AI considered, but marks DO NOT PLACE.

JOURNAL
- Only QUALIFIED ML pending plans are added to the ML execution journal.
- Rejected candidates do not contaminate live ML entry-quality feedback.
- ML-specific journal summary is separated from generic/statistical pending plans.
