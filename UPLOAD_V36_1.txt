SETUP ORDER
1. Create a Cloudflare D1 database.
2. Run cloudflare-d1-schema.sql in D1 Console.
3. Create a Worker and paste cloudflare-worker.js.
4. Bind D1 as variable DB.
5. Add encrypted Worker variable WEBHOOK_TOKEN = a long random token.
6. Deploy Worker.
7. In TradingView, open XAUUSD on 1-minute chart and add tradingview-xauusd-m1.pine.
8. Create alert: Condition = OneMonth XAUUSD M1 Feed Bridge -> Any alert() function call.
9. Set webhook URL to: https://YOUR-WORKER.workers.dev/tv-webhook?token=YOUR_RANDOM_TOKEN
10. Enable the alert.
11. Add GitHub secrets TV_FALLBACK_URL and TV_FALLBACK_TOKEN.
12. Run Actions -> Update XAUUSD data pack once.
13. Check feed-health.json. Fallback should show ONLINE/READY after TradingView has sent bars.
14. Run AI Background Learning once.
15. Open /Trading/reset.html once.

EXPECTED APP STATES
TWELVE DATA / PRIMARY = normal live feed
TRADINGVIEW LIVE / LIVE_AUGMENT = app merged newer M1 bars directly from fallback
TRADINGVIEW FALLBACK = GitHub updater switched to TradingView because Twelve Data failed/staled
FEED HOLD = live data is stale/divergent/both sources down; plans can remain references but must not be placed
LAST SESSION = market closed; planning from last session is allowed, revalidate on open

IMPORTANT
TradingView fallback is designed around confirmed 1-minute bars, not tick-by-tick streaming.
The webhook write endpoint is secret-token protected. The public read endpoint contains only XAUUSD OHLC market data.
